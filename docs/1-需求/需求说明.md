# vault-panel 需求说明(v0.3,已按实现更新)

> 状态:**M0~M3 已开发完成,待你运行验证**。
> v0.3 相比 v0.2:界面确定为表格;Excel 不再引入 exceljs,改为自带零依赖的 .xlsx 生成器;导入只支持 CSV;分组改为顶部筛选按钮(不做折叠)。

## 1. 产品定位

**本机运行的账号密码管理网页**:在浏览器里记录各类账号的用户名和密码,随时查看,可导出为 Excel。

- 只在电脑上使用,只监听 `127.0.0.1`(沿用现有面板的方式)。
- 数据存成本机上的一个**加密文件**,用主密码解锁。
- 不做手机端、不做云端、不做浏览器自动填充、不做多人共享。

## 3. 安全需求(精简,但必须有)

| 编号 | 需求 |
|---|---|
| S-01 | 密钥派生用 **scrypt**(Node 内置,无需依赖;Node 18 无内置 Argon2),加密用 **AES-256-GCM**,不自己实现算法 |
| S-02 | 保险库文件整个加密,磁盘上没有明文;文件头记录版本和 KDF 参数 |
| S-03 | 令牌不放 URL,改用 `HttpOnly; SameSite=Strict` Cookie |
| S-04 | 校验 `Host` 与 `Origin`,防 DNS rebinding 和跨站请求 |
| S-05 | 严格 CSP,前端零外部依赖、零 CDN、零统计 |
| S-06 | 主密码输错限速 |
| S-07 | 锁定后服务端丢弃解密内容,页面不残留明文 |
| S-08 | 测试覆盖:加解密往返、错误密码失败、**篡改一个字节必须解密失败** |
| S-09 | 在 `SECURITY.md` 写明:不防本机木马、不防解锁状态下被他人使用、主密码丢失无法找回 |

## 4. 非功能需求

| 项 | 要求 |
|---|---|
| 平台 | Windows / macOS / Linux,Node.js ≥ 18 |
| 规模 | 几千条账号内流畅 |
| 可靠性 | 保存失败不损坏原文件 |
| 依赖 | **零运行时依赖**(Excel 由自带模块生成) |

## 5. 数据与技术方案

- **保险库格式**:自有格式(文件头 + AES-256-GCM 加密的 JSON)。不使用 KDBX。
- **存放位置**:默认 `~/.vault-panel/vault.enc`,可在配置里改;默认端口 8766(避开 mutagen-panel 的 8765)。
- **Excel 导出**:自带约 150 行的 `xlsx.ts`(ZIP + 内联字符串),生成真正的 `.xlsx`,含加粗冻结表头和列宽;单元格全部按文本写入,防公式注入。不引入 exceljs,减少供应链风险。
- **备份与多机**:保险库是单个文件,想在多台电脑间用,自己拷贝或用 Mutagen/网盘同步该文件即可,程序不内置同步。

```
 浏览器 ──(127.0.0.1 + Cookie)──▶ vault-panel(Node.js) ──▶ vault.enc(加密文件)
                                          └──▶ 导出 .xlsx
```

| 模块 | 职责 | 来源 |
|---|---|---|
| `crypto` | 密钥派生、加解密 | 新写 |
| `vault` | 读写保险库、账号模型、原子保存、备份 | 新写 |
| `export` | 生成 xlsx | 新写 |
| `server` | HTTP 接口、鉴权、加固 | 改自 `server.ts` |
| `config` | 保险库路径、超时等 | 改自 `config.ts` |
| `web/index.html` | 单文件前端 | 改自现有页面 |

可删除:`mutagen.ts`、`pull.ts`、`remote.ts`、`actions.ts`、`files.ts`、`servers.ts`及其测试。
